Build a 3D portfolio site
with a video hero, step by step.

A plain-language walkthrough for generating the hero video and building the full scroll-driven 3D website using Claude Code — no technical background required to follow along.

01
Part One — The Hero Video
Generate the video that plays behind the headline.
This is the first thing visitors see — you at your desk, warm lighting, code on screen. Keep it short, it loops in the background.
01

Decide what it should show

  • You at your desk, monitors with code/diagrams visible
  • Warm, cozy lighting — like a late-night build session
  • Subtle hand movement, like you're explaining something
  • 5–10 seconds is enough — it just needs to loop cleanly
02

Generate it with Higgsfield

  • Use your reference photo as the starting image
  • Ask for an image-to-video generation — keep motion subtle, camera steady
  • Pick a model built for realistic image-to-video, not big dramatic camera moves (the site already adds 3D motion on top)
  • Generate a few versions and pick the cleanest one
03

Clean it up

  • Mute any audio — the site autoplays muted anyway
  • Trim to 5–10 seconds, set to loop
  • Compress under 8MB so the site loads fast
04

Save the final file

Name it something simple like hero-video.mp4 and keep it somewhere easy to grab — you'll hand it to Claude Code in Part Two.

02
Part Two — Building the Website
Hand the instructions to Claude Code, let it build.
Claude Code is the builder. Your prompts are the instructions. You just answer questions and review the result.
01

Get your building blocks ready

  • The master prompt — describes all four 3D scenes, your job history, colors, fonts
  • The Scene 3 prompt — the floating skills graph, built separately
  • The hero video from Part One
02

Open Claude Code

Open it inside an empty project folder. It'll set up everything from scratch — you don't need to create any files yourself first.

03

Hand over the main prompt

Paste in the full master prompt and tell it to build the site. It already has the ui-ux-pro-max skill installed, so it'll apply that automatically for layout and polish — nothing extra needed from you here.

04

Let it build

  • Sets up the Next.js project
  • Installs the 3D tools — React Three Fiber, GSAP, Framer Motion
  • Builds each section: Hero, About, Experience, Skills, Education, Contact
  • Wires up scroll animation so the camera "flies through" the 3D world as you scroll

This takes a while. If it asks questions along the way, just answer in plain words.

05

Add your hero video

When it reaches the hero section, hand it your hero-video.mp4 from Part One. It'll wire it up as the background automatically.

06

Build Scene 3 separately

Paste in the dedicated Scene 3 prompt right after the main build — the floating skill nodes that light up when you hover a skill card. This is its own focused step.

07

Preview it

  • Does the video play smoothly in the hero?
  • Do the 3D scenes look right as you scroll?
  • Does hovering a skill card light up the right node in Scene 3?
  • Is your job history accurate and in order?
08

Fix anything that looks off

No code knowledge needed — just describe the change in plain words ("make the orange more red," "this animation is too fast") and Claude Code edits the code directly.

09

Push to GitHub

Once you're happy with it, ask Claude Code to push the project to your GitHub account so it's saved and backed up.

10

Deploy on Vercel

Connect the GitHub repo to Vercel (or have Claude Code do it). You'll get a live link to share — your own domain, or a free .vercel.app one to start.

03
Quick Recap
The whole thing, five steps.
Generate hero video → Hand prompts to Claude Code → Build site + Scene 3 → Preview & refine → Push + deploy
04
If Something Goes Wrong
Common hiccups, plain fixes.
Video doesn't play on the live site
It's probably too large a file. Compress it smaller and re-upload.
3D scenes look laggy or slow
Ask Claude Code to reduce the number of floating shapes or particles — fewer objects means smoother performance on most computers.
Site looks broken on phone
Tell Claude Code "this needs to work well on mobile too" and point out exactly what looks wrong.
You don't like a color or font
Just say so in plain words — no technical terms needed. Claude Code will make the change directly.
